eRH-Camusat

Application mobile RH de Camusat

Installer sur iPhone
Ouvrir eRH-Camusat

iPhone · gratuit, sans App Store

  1. Ouvrez cette page avec Safari et appuyez sur Ouvrir eRH-Camusat : c'est la même application que sur Android.
  2. Appuyez sur le bouton Partager (le carré avec une flèche vers le haut).
  3. Choisissez Sur l'écran d'accueil, puis Ajouter.
  4. L'icône eRH-Camusat s'ajoute à votre écran d'accueil et s'ouvre comme une application.
    Télécharger l'application

    Android · fichier APK (environ 75 Mo)

    1. Appuyez sur Télécharger l'application.
    2. Une fois le téléchargement terminé, ouvrez le fichier eRH-Camusat.apk.
    3. Si Android bloque l'installation, autorisez les « applications inconnues » pour votre navigateur, puis revenez.
    4. Installez, puis connectez-vous avec vos identifiants eRH.

    Version iPhone : ouvrez cette page depuis votre iPhone.
